# ToastyReplay-Lite

**Extremely Small replay recording and playback with extended support**

---

## <cg>Using the menu</c>

1. Press **F8** to open ToastyReplay Lite.
2. Press **F1** or select **Record**.
3. Complete the level.
4. Select the saved macro and press **Replay**.

## <cj>Replay Features</c>

- Vanilla input recording and playback
- Practice Fixes
- Automatic replay saving
- Optional frame fixes
- TPS bypass
- Speedhack
- Replay-specific random seeds
- Frame Stepper
- Safe Mode

## <co>Compatibility</c>

ToastyReplay-Lite records vanilla inputs. Recording is NOT compatible with the following gameplay enhancements:

- CBF (Click Between Frames)
- CBS (Click Between Steps)
- Frame Extrapolation (Megahack) ~~Situational~~
- ANY other TPS bypass, Whether Silicate, Megahack, GDH, Eclipse, list goes on...

Find advanced options in the geode settings for the more experienced botters.
